# Board Night — Design Elements

Colors, assets, and reusable UI patterns used in the app, isolated from app logic. Fonts intentionally excluded.

## Contents
- `Style Guide.dc.html` — visual reference: colors, card/button/input patterns, avatar swatches, logo.
- `assets/logo_color.png` — app logo.

## Color palette
**Backgrounds/surfaces:** app bg `#12151c`, card surface `#262d3d`, input bg `#1c2230`, avatar placeholder `#2f3750`

**Brand/accent:** primary teal-green `#36996f`, maroon `#9b3f45`, navy/blue `#8fb0c7`, orange `#e29314`, red `#ce3b30`, cream `#ece7da`

**RSVP status:** yes `#327724`, maybe `#e29314`, can't go `#ce3b30`, no response `#4b5164`

**Text:** primary `#ece7da`, secondary `rgba(236,231,218,0.55)`, links `#8fb0c7` (hover `#a9c4d6`)

## Patterns
- Cards: 16px border-radius, 16px/18px padding, shadow `0 4px 14px rgba(0,0,0,0.25)`
- Avatars: 36px circles (26px small variant), solid color fills
- Primary button: 14px radius, brand color fill, cream text
- Inputs: 9px radius, dark bg, subtle border
